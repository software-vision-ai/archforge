# Help and support

## About Archforge

The **Help** button (the question mark in the bar at the top), or **Archforge ▸ About Archforge…**
on macOS, opens **About Archforge**: what Archforge is, and how to support it.

<!-- picture: home-about light | About Archforge, with the ways to support the project -->

## Supporting Archforge

Archforge is free, and a contribution unlocks nothing: every feature stays free for everyone. If
it helps your work, you can support its development:

- [Ko-fi](https://ko-fi.com/dejanwho): a one-time tip.
- GitHub Sponsors, one-time or monthly, for the software-vision-ai organization, once its
  Sponsors profile is published. Until then, About Archforge says *Not set up yet*.

Payment happens on the provider's page in your browser; Archforge never sees it.

## Reporting a problem

Report a bug or suggest an improvement as an issue in the
[Archforge repository](https://github.com/software-vision-ai/archforge/issues). Say what you did,
what you expected and what happened, and which system you use; a screenshot helps.

Report a security problem privately, as the repository's `SECURITY.md` describes, never in a
public issue.
